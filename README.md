# بوابة المستشفيات التعليمية — Hospital Main Hub 🇮🇶

منصة موحدة ومتقدمة لإدارة المستشفيات التعليمية، الخفارات الطبية، وجداول الأطباء المقيمين والدوريين مع مزامنة سحابية حية عبر خادم Cloudflare.

## 🌟 المميزات الرئيسية (Key Features)

1. **بوابة المستشفيات الموحدة (Multi-Hospital Hub):**
   - إدارة شاملة لمستشفيات متعددة:
     - مستشفى البصرة التعليمي (Basra Teaching Hospital)
     - مستشفى الموانئ التعليمي (Mawani Teaching Hospital)
     - المستشفى العراقي التعليمي (Iraqi Teaching Hospital)
   - إمكانية إضافة مستشفيات جديدة بكامل هيكليتها الإدارية والتنظيمية بنقرة زر واحدة.

2. **نظام المصادقة والصلاحيات الذكي (Dual-Role Auth):**
   - تسجيل دخول عبر كلمة المرور يتم التحقق منها على الخادم، بأربع صلاحيات: المالك، المدير، مقيم التخدير، المستخدم.
   - كلمات المرور مخزنة مشفرة على الخادم ولا تظهر إلا للمالك، ولا تُكتب في الكود أو في هذا الملف.

3. **شريط التنقل الموحد (Universal Responsive Navigation):**
   - قائمة تنقل علوية سريعة وموحدة في كل الصفحات مع مبدل ديناميكي للمستشفيات، زر تبديل الوضع الليلي (Dark/Light mode)، وزر تثبيت التطبيق.

4. **قائمة الخفراء الحالية (Active Duty Roster - Home):**
   - عرض فوري للأطباء الخفراء مع عداد تنازلي ثلاثي الأبعاد (Flip Clock).
   - تأثيرات بصرية احتفالية عند اكتمال جدول الخفارة.
   - نسخ تقرير خفارة رسمي منسق بضغطة زر لمشاركته عبر واتساب وتيليغرام.

5. **تسجيل الخفارات الذكي (Smart Signup):**
   - إكمال تلقائي ذكي لأسماء المقيمين (Ghost-text autocomplete).
   - حقول ديناميكية للأرقام والملاحظات.

6. **مجدول الخفارات الشهري (Monthly Duty Matrix Scheduler):**
   - توزيع ومصفوفة تفاعلية لكافة أيام الشهر والاختصاصات مع دعم السحب والتمرير (Swipe & Drag).

7. **تطبيق ويب تقدمي (Progressive Web App - PWA):**
   - يدعم التثبيت المباشر على الهواتف وأجهزة الكمبيوتر، مع نسخة احتياطية للعمل بدون إنترنت، وتصل التحديثات إلى التطبيقات المثبتة تلقائياً.

8. **مزامنة بيانات سحابية موحدة (Cloudflare Worker + D1):**
   - البيانات محفوظة في قاعدة بيانات Cloudflare D1 عبر الخادم `hosp-hub-api`، ويُرفع عند الحفظ ما تغيّر فقط مع دمج تعديلات المستخدمين المتزامنة.
   - كل تعديل يحتفظ بالنسخة السابقة لمدة 120 يوماً.
   - تفاصيل التشغيل والنسخ الاحتياطي في [`worker/README.md`](worker/README.md).

## 🚀 كيفية تفعيل الموقع عبر GitHub Pages (Live Deployment)

لتشغيل الموقع أونلاين مجاناً وبسرعة عبر GitHub Pages:
1. اذهب إلى إعدادات المستودع: **Settings** > **Pages**
2. تحت قسم **Build and deployment** > **Branch**:
   - اختر الفرع: **`main`**
   - اختر المسار: **`/ (root)`**
   - اضغط **Save**
3. سيصبح الموقع متاحاً ومباشراً خلال دقيقة واحدة على الرابط:
   👉 **https://mhub96.github.io/IQ/**

9. **الحسابات الشخصية (Personal Accounts):**
   - إنشاء حساب باسم الطبيب ورقم هاتفه، مع تحقق مباشر أثناء الكتابة من مطابقتهما لجدول المستشفى المختار، ثم موافقة المالك أو مدير المستشفى.
   - «نسيت كلمة المرور؟»: طلب يوافق عليه المدير، ثم يختار الطبيب كلمة مرور جديدة.
   - صفحة `account.html` لإدارة الحساب والموافقات والصلاحيات.

10. **الإشعارات والتفاعل (Notifications, Likes & Comments):**
   - جرس إشعارات في كل الصفحات، وإعجابات وتعليقات على بطاقات الخفراء (باسم الطبيب أو بلقب مجهول عشوائي).

## 🧪 النسخة التجريبية (Beta)

هذا المستودع هو النسخة التجريبية: الموقع على Cloudflare (`https://hosp-hub-beta.mrjuniversity.workers.dev`) والخادم `hosp-hub-api-beta`، وكلاهما يستخدم **نفس قاعدة البيانات** الحية. التفاصيل في [`worker/README.md`](worker/README.md).

بعد تعديل أي صفحة: `cd tools && npm install && npm run css` لإعادة بناء `tailwind.css`.
